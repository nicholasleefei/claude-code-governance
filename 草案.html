候选

T-13 · 例行任务定时化 · 真无人值守拟定 → Z-13

  • 范围跨天/跨会话的例行动作（首推 外链巡检 周检）；机制＝Windows 任务计划程序 到点拉起无头 claude -p 执行。
  • 背景Claude 会话内定时/循环只在当前会话存活期有效、约 7 天自动过期——扛不起"每周固定必跑"；云 Routine 读不到本机 E:\。本机真定时只能走 OS 调度＋claude -p。
  • 无人值守默认只读优先（--permission-mode plan）；上限护栏（--max-turns / --max-budget-usd）防跑飞烧钱；stdout+stderr 落 过程记录（只增不改）；exit≠0 即告警。
  • 放宽条件需自动落纪要时才放宽：--permission-mode acceptEdits 且 --allowedTools 限定到 过程记录/**，不放全写。
  • 认证不用交互登录（OAuth 约每周过期、无头下不可靠）；任务环境用 setup-token / ANTHROPIC_API_KEY。出网 HTTPS_PROXY 与 git 的 http.proxy 是两回事，分别配。
  • 注记哪些任务上系统定时、频次，按本机实际分批启用并登记；全部动作可审计、可回滚。
  • 状态候选 · 在审 · 待批准入 Z-13。
