适用范围 Z-01 · 已批准 2026-09-03

本总则适用于本机（账号 pc）上启动的全部 Claude Code 会话——任意目录与项目，含本工作区自身。效力以「本机用户级配置可被读取」为界：读取该配置的形态（CLI／桌面端会话）在适用内；读取不到的形态（claude.ai 网页端、其他电脑与其他账号、企业托管层）不在其内。本总则为全机默认基线，效力自高而低：当次会话临时指令 > 红线条款（不豁免）> 项目级规则（可覆盖软规则）> 总则软规则。

模型文件统一仓 · E:\01-model Z-02 · 已批准 2026-09-03

本机所有模型文件的默认落点为 E:\01-model\，一律不落入项目目录。E:\01-model\ 按「编号-模型名@版本」一模型一夹；根目录 index.html 总台账负责编号登记与查找，每夹内 index.html 为该模型说明书；任务用模型先查台账、有则复用、不重复下载。工具自带缓存经环境变量收拢至 E:\01-model\_cache\<工具>\（不拆一模型一夹）。项目内联调必需的小模型为例外，须登记台账并用 .gitignore 排除。定期巡检：凡 E:\01-model 之外的大体量模型文件一律归拢或登记。

技能台账 · E:\02-skill（登记制） Z-03 · 已批准 2026-09-04

本机 Claude Code 的 skill（含用户要求下载部署的外部 skill、与要求沉淀的自写 skill）不强搬、不强拆、不做目录联接——各自待在标准生效位置（用户级 ~/.claude/skills、项目级 .claude/skills、插件内）。E:\02-skill\ 仅作台账登记处：根 index.html 为总台账，登记“装了什么 / 何时装 / 在哪 / 能干什么”，供统一管理（查找、删除、测试）。编号 S-001… 只增不复用，与 E:\01-model 的模型 M 号相互独立。新增/删除/停用任一 skill 后须更新台账；外部下载记来源与安装日期，自写沉淀记“自写沉淀 · 日期”；能力权威说明以其所在目录原生 SKILL.md 为准，台账只作索引不另抄。停用不删夹，状态改“停用（可删）”。

本机 Claude Code 生态的 MCP 服务器与 CLI 工具，同样采用登记制：实体各归标准生效位置（MCP 注册于 Claude Code 配置——项目 .mcp.json / 用户级 ~/.claude.json 等；CLI 位于 PATH/已知路径），不搬文件、不做目录联接。E:\03-mcp\ 与 E:\04-cli\ 各设 index.html 总台账登记（E 盘根下平级，与 E:\01-model、E:\02-skill 相互独立）。编号 MCP-001… 与 CLI-001… 只增不复用。登记含：名称、能力、来源、添加日期、位置/注册 scope、启动命令、状态；含凭据/远程项只记所需环境变量名、明文不入台账；npx/uvx 或工具自动托管者只登记不搬家（物理收拢缓存另行批准）。新增、删除、停用任一 MCP/CLI 后须更新台账；跨 skill/MCP/CLI 的同源工具做编号互链，不重复登记。

治理体系多机部署 · 主仓权威 · 使用机只读 Z-10 · 已批准 2026-09-04

体系分层——主控机为本机（规则主仓所在，唯一写者）；使用机为其它电脑（只读）。主仓公开托管于 github.com/nicholasleefei/claude-code-governance，规则修订只认主仓；使用机以匿名方式 git clone / pull（公开仓无凭据即无写权限），永不 push。各使用机按装机提示词从主仓拉取并编译本机 CLAUDE.md 镜像：通用规则照抄，本机存储/落点规则按该机实际，不照抄主仓盘符；skill/model/MCP/CLI 不随仓镜像，各机按需安装、按需登记。
