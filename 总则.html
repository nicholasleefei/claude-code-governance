秘书长 · 治理体系三层级联 Z-15 · 已批准 2026-09-13

治理体系角色自此分三层。秘书长 = 顶层主会话（用户在对话里的"我"）：常驻、对话不中断，负责与用户单线程聊需求、逐条拍板总则与章程修订；决议需落文件时把整批一句交办给书记长，不亲自逐项写文件。小希·书记长（首席书记）= 秘书长派出的执行臂：受交办后编排 ≥3 书记子 Agent 并行落文件、汇总核验、写纪要、回报。书记团 = 受小希派出的并行子 Agent。术语桥接：治理文件首次出现"秘书长"处一律括注"= 顶层主会话"，与既有"主会话/顶层主会话"无矛盾共存。本条是 P-9 主会话常驻原则的具体体现：任何拆分不让用户等待、不让主会话下线；书记长派活不越权、不替用户做权限外的事。

例行任务定时化 · 真无人值守 Z-16 · 已批准 2026-09-13

跨天/跨会话的例行动作（首推外链巡检周检）走 OS 级真定时，不依赖常驻会话：机制＝Windows 任务计划程序到点拉起无头 claude -p 执行。理由：会话内定时/循环只在当前会话存活、约 7 天自动过期，扛不起"每周固定必跑"；云 Routine 读不到本机 E:\。无人值守默认：只读优先（--permission-mode plan）；用 --max-turns / --max-budget-usd 护栏防跑飞烧钱；stdout+stderr 落 过程记录（只增不改）；exit≠0 即告警。需自动落纪要才有限放宽：--permission-mode acceptEdits 且 --allowedTools 限定到 过程记录/**，不放全写。认证不用交互登录（OAuth 约每周过期、无头下不可靠），用 setup-token / ANTHROPIC_API_KEY 环境变量（遵 Z-09，只记变量名）；出网 HTTPS_PROXY 与 git 的 http.proxy 是两回事、分别配。哪些任务上系统定时、频次，按本机实际分批启用并登记，全部可审计、可回滚。本条只定机制，具体任务启用另行登记批准。
