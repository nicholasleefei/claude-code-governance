【Claude Code · 总则安装提示词 · 使用机装机】

用途：把一台新电脑配成"只读使用机"——遵守主仓通用规则、能读规则原文，但永不改动主仓、永不上传。
用法：在目标电脑第一次打开 Claude Code 时，把下面整段粘给它执行。
规则更新：在主仓 git pull 即可，使用机不参与改规则。
============================================================

你正运行在一台【使用机】上。任务是照"主仓规则"把本机配成只读使用机：遵守通用规则、能读规则原文，但【永不修改主仓、永不 push】。

【第一步 · 摸清本机】
确认 git 可用。问用户三件事：① 这台电脑主要干什么用？② 有没有已想好要装的模型 / skill / MCP？③ 打算把规则仓放在哪个目录（给建议，不强求）。

【第二步 · 只读拉取主仓】
把规则仓 clone 到用户指定目录，用只读凭据。明说纪律并写入本机备忘：本机永不 commit / push，只 git pull。

【第三步 · 编译本机 CLAUDE.md（关键）】
读主仓里的总则结论板，分两层处理：
- 通用行为规则（适用范围 / 多 Agent 协作 / 会议 / 纪要等）→ 照抄。
- 本机存储规则（E:\model / E:\skill / E:\mcp / E:\cli 的落点与台账）→ 属于主仓那台机的布局，【不要照抄盘符】。问清本机是否也想要类似统一仓；不要就写"本机不设统一仓，按需安装"。
最后把编译结果写入 C:\Users\<本机用户名>\.claude\CLAUDE.md（UTF-8），并注明"由主仓编译、只读；改规则请回主仓"。

【第四步 · 按需装工具（用户不点就不装）】
只把主仓台账里登记过的 skill / MCP / CLI / 模型列成"菜单"给用户挑，按需逐个装到本机标准位置。绝不默认全装——各机场景不同。

【第五步 · 收尾】
提示用户：新开的会话才会读到新 CLAUDE.md；规则更新时在本机 git pull 即可。装机完成情况【不写回主仓】（只读机不留记录），由用户在主仓那台机补记到过程记录。
