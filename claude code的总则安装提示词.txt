【Claude Code · 总则安装提示词 v2 · 使用机装机（只读）】

用途：把一台新电脑配成本体系「使用机」——遵守通用总则、能读规则与纪要原文，但永不改规则、永不 push 主仓。
规则主仓（公开 · 任何人可读）：https://github.com/nicholasleefei/claude-code-governance
你正运行在一台使用机上。执行以下五步；拿不准就问用户，不要自作主张。

【第〇步 · 自我核对】确认已把主仓 clone 到本机某目录（示例：git clone https://github.com/nicholasleefei/claude-code-governance.git）。若尚未 clone，请先请用户执行 clone 再继续。本机对主仓只读——匿名 https 克隆天然无写权限，禁止在本仓内 git commit / push。

【第一步 · 摸清本机】向用户问三件事：① 这台电脑主要用途；② 打算按需安装哪些 skill / MCP / CLI / 模型（可稍后答）；③ 主仓 clone 到哪个目录（记下，供日后 git pull 更新规则）。

【第二步 · 编译本机 CLAUDE.md】读取主仓内 总则.html 的结论板，分两层处理：
- 通用规则（适用范围 Z-01 / 多 Agent 协作 Z-05 / 外链巡检 Z-07 / 纪要即记忆 Z-08 / 多机部署 Z-10 等行为层）→ 逐条照抄。
- 本机存储与落点规则（Z-02 模型仓 / Z-03 skill 台账 / Z-04 MCP·CLI 台账中含 E:\01-model、E:\02-skill 等盘符的段落）→ 属主仓所在机（主控机）的布局，不要照抄盘符；问清本机是否建同构目录——要则把 E:\ 换成本机实际盘符，不要则写「本机不设统一仓，按需安装、自行登记」。
把编译结果写入 C:\Users\<本机用户名>\.claude\CLAUDE.md（UTF-8 无 BOM），并在开头注明「由主仓总则编译 · 只读镜像 · 改规则请回主仓（主控机）」。

【第三步 · 按需装工具（菜单制）】只把主仓台账里登记过的 skill / MCP / CLI / 模型（E:\02-skill / E:\03-mcp / E:\04-cli 与 E:\01-model 的 index）列成菜单供用户挑选；选中者装到各标准生效位置（skill→~/.claude/skills；MCP→.mcp.json / ~/.claude.json；CLI→PATH；模型→用户本机目录）。绝不默认全装。

【第四步 · 更新与收尾】规则更新：在本仓目录执行 git pull（保持只读）；pull 后若 CLAUDE.md 需重编译则重跑第二步。凭据纪律：本机任何文件、纪要、配置不得落明文 API key / 口令 / token，只用环境变量名；本机产出的纪要若需入主仓，交主控机在那边提交，本机不 push。完成后告知用户：新开会话才读到新 CLAUDE.md；本机不留假记录。

【边界】若用户想在本机改规则或回写主仓——主仓只认一台主控机（唯一写者）；确需改动请回主控机操作，或另行议定升格。
