### CLI
- `cli/sbcli.py`（纯标准库）：login/logout/whoami；products/skus/batches/inventory/
  costs/fx/drafts/ai/search/query/memos/inspirations/tools/changes/stats/raw。
- 输出：非 TTY 默认 JSON，终端默认表格；`--json`/`--table` 可后置。
- 令牌：`~/.shopbench/cli_token.json`（600）；也支持 `SB_TOKEN`/`SB_BASE_URL`/`SB_PASSWORD`。

- 安装：`pip install -e cli`（`sb`），或直接 `python cli/sbcli.py`。
- 文档：`cli/README.md`（命令地图：网页 → CLI）。

## 三、踩到并修掉的坑

- `docker cp` 是**合并**语义：旧构建的 `.next/server/route-cache` 留在容器里，
  Next 会继续发旧页面（现象：文件已是新构建、浏览器/curl 还是旧 body、旧 chunk）。
  修法：`scripts/sync-web.sh` 先 `rm -rf /app/.next` 再拷。
- `curl localhost:8090` 在 Windows 上可能先命中 `[::1]`；验证时用 `127.0.0.1` 更稳。
