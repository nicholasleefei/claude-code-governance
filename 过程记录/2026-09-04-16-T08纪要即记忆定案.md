- 两层触发——治理层：凡会议/候选议处/定案/收尾批，落档即同步写纪要，编号 YYYY-MM-DD-NN-主题，只增不改（历史由 git 保证）；通用层：任何项目内凡预期跨会话/跨天继续的复杂工作，主会话收尾或临近结束时留一份简短「交接纪要」（内容＝已完成/未完成/下一步/关键上下文/所在位置），就近放该项目（项目 过程记录 或 README 等文档）。

- 豁免与纪律：琐碎问答不记；纪要内不落明文凭据（呼应 Z-09 方向）。
- 通俗解释：纪要＝工作交接单。续活前先看交接单知道干到哪；收工写一页；换会话/换机靠交接单不靠嘴上说。
