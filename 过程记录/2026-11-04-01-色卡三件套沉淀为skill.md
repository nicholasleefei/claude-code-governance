## 2. 方法定型

### 2.1 三件套（缺一不可）

| 件 | 内容 | 硬要求 |
|---|---|---|
| ① 颜色 | HEX / RGB / HSL / CIELAB / 占比 / 色名 | 参数级、**实测**；浅色透色款自动回退全像素 k-means |
| ② 金句（氛围） | 家族名 + 情绪词 + 英文原句 + 中译 + 出处 + **画面锚点** | 出处真实可查；同卡各组出处互异；不与已用金句重复 |
| ③ 氛围图描述词 | 地点 + 时间 + 光线 + 前中后景 + 生活痕迹 + 花卉绿植 | **景别必标注**并混排；**不出现产品实物** |

### 2.2 核心机制
**每句金句配一个画面锚点**——把情绪落到看得见的物件（一束光、一段布、一枝花），使颜色、金句、画面三者同向；锚点必须在③里找得到。

### 2.3 另立两条
- 画面必须**具体**（地点/时间/光线/层次/生活痕迹），不写抽象氛围——第一版「一个石头一片海」偏色块就是反例。
- 景别**大小不拘但要混排**（大景/中景/小景），14 幅不雷同。

## 3. 三条关键技术坑（都已写进 skill）

1. **JPG 预览器不认**：产品图多为预览器不支持的编码，`Read` 直接看会返回 unsupported，必须先转 PNG（脚本自动转 `预览/`）。
2. **浅色产品主色被吃掉**：饱和度掩膜（S>0.15 且 V>0.12）把乳白/透明/珠光当背景丢掉——**有色像素占比 <15% 必须回退全像素 k-means**。本次回退：02 冰川雾霾蓝、05 极光透彩、07 奶白月光、14 白透银霜。
3. **命名 ≠ 实测**：产品名只是卖点命名，不是色彩事实。实测推翻三例——07「奶白月光」实为**暖奶米**（#B1A485/#C3B388）、05「极光透彩」实为**暖白半透明**（#BDB9B5/#E9E5E1，无绿）、11「马卡龙糖果」实为**饱和糖果色**（#D23C5D/#7EB1D9，非冲淡粉彩，故第三句金句换 Kipling《If—》）。据此另校正 04、12 两幅。

### 9.2 方法层三条纠正（本节核心）
1. **颜色按角色用，别逐色硬套**：主 55–70% / 辅 20–30% / 点缀 3–10% / 暗部 / 环境色（白灰木土天光自由用）；允许明度±20、饱和±15、同族色相±15°；hex 只作锚点，环境光可改写颜色；光学现象（极光/折射）可超出提取色但面积要小。配色原理落地：60-30-10、同类色统一、互补只作小面积点缀、明度对比优先于色相对比、饱和度阶梯、空气透视、冷暖对照、主导色相 ≤2 族 + 1 点缀。
2. **降级规则**：取色失败 / 全图近乎无色 / 有色像素过少 → 退回「颜色名 + 调性描述」，标 `palette_source: fallback`，**绝不为凑参数编 hex**。
3. **情绪必须与金句同向**：每款加**情绪总纲**（极性·能量·温度＋一句人话，中英各一），并做**情绪-画面一致性校验**——积极金句不能配死寂画面，消极金句不能配喧闹画面；**消极情绪同样要匹配**（不是每幅都要积极好看）；复杂型只留一个主情绪、另一种作余味。
