**P-9 权威正文要点（已原样落章，含排版略作 HTML 化）**
核心原则：顶层主会话（用户对话中的"我"）常驻、对话不中断；派出的各智能体只是主会话"可随时调整的延伸"，不是对话的交接对象。任何拆分都不得以"让用户等待 / 让主会话下线"为代价；主会话同一时刻只回一件事（单线程），子智能体并行只压缩墙钟时间、不增加对话带宽。
规则分四节：**一、何时拆**（三问全中才拆：够大 / 可切出独立并行子块 / 结果能验收；反向不拆＝需反复对齐、小活、强耦合）；**二、拆几个**（执行数＝独立子块数，常规 2–5；结果关键/不可逆/高风险→＋1 核验；需留痕→＋1 纪要；指挥者（小希型）不计工人数；单批建议 ≤6，超则分批）；**三、怎么排**（顶层常驻随时可调；互不依赖→一批并行、有因果→流水线、要过质量关→末尾对抗性核验；只读/规划/执行/核验分开；简报自足、各管各、只回结论；拍板权在用户、防越权）；**四、项目家族参考模板 F1–F6**（调研情报 / 数据活 / 创作媒体 / 工程开发 / 产品搭建 / 模拟仿真）。
